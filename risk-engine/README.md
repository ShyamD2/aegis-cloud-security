# Security Risk Engine
## Project AEGIS - Phase 09

Calculates a deterministic, explainable $0-100$ contextual risk score factoring in severity, asset criticality, identity privilege, graph blast radius, and behavioral anomalies.

### Score Classifications
- 0–25: LOW (Log only)
- 26–50: MEDIUM (War Room alert)
- 51–75: HIGH (Approval-gated containment)
- 76–100: CRITICAL (Autonomous containment)
