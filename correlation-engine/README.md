# Correlation Engine Module
## Project AEGIS - Phase 05 / Phase 06

The AEGIS Correlation Engine synthesizes multi-source events (CloudTrail, VPC Flow Logs, Route 53 DNS, GuardDuty findings) across time windows to detect distributed attack campaigns.

### Core Responsibilities
- Sliding window event aggregation.
- Cross-account identity linking.
- Campaign clustering and alert de-duplication.
