# Detection Engine Module
## Project AEGIS - Phase 05 / Phase 06

The AEGIS Detection Engine provides deterministic, sequence-based threat detection against multi-account cloud telemetry.

### Core Responsibilities
- Rule registry and evaluator for high-fidelity detection rules.
- Identity and resource context enrichment.
- MITRE ATT&CK mapping for cloud tactics and techniques.
- Synthetic event replay for unit testing.
