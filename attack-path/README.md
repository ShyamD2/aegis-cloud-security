# Attack-Path & Blast-Radius Engine
## Project AEGIS - Phase 08

Models cloud relationships in Amazon Neptune (openCypher/Gremlin) to map traversable identity paths and calculate blast radius.

### Entities Modeled
- IAM Users, IAM Roles, Trust Policies, Managed/Inline Policies.
- Workload resources: S3 Buckets, EC2 Instances, RDS Databases, Secrets.
- Network boundaries: Security Groups, VPCs, Peering connections.
