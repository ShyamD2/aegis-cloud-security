# Purple-Team Attack Lab
## Project AEGIS - Phase 13

Isolated, safe, and automated attack simulation environment within the Security Lab account.

### Attack Scenarios Modeled
1. IAM access key compromise & rapid privilege escalation.
2. Suspicious cross-account AssumeRole chaining.
3. S3 security misconfiguration (public bucket policy injection).
4. Dangerous security group rule addition (`0.0.0.0/0` on port 22/3389).
5. CloudTrail logging disruption attempt.
